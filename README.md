# Enea Zani

**UX designer and full-stack developer in Parma, Italy.** I design interfaces that
are simple to use and build websites that stay fast and maintainable: design
systems, accessible components, React and TypeScript, technical SEO.

I work with companies and professionals in Parma, Emilia-Romagna and across
Italy, remotely.

## What I do

- **Web design and development** — custom sites, e-commerce, landing pages.
  Written scope and fixed price before work starts.
- **Design systems** — component inventory, token governance, Figma + React library.
- **Accessibility** — WCAG 2.2 AA audits with keyboard and screen-reader checks.
- **Performance** — Core Web Vitals measured on real devices, not in a lab only.
